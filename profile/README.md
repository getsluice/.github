<h1 align="center">Sluice</h1>

<p align="center">A file manager for your servers.</p>

Pick a saved site, browse the server, double-click a file to edit it in VS Code, and every save goes straight back to the server. A transfer panel at the bottom shows each upload as it happens.

- **Saved sites:** one click connects, and passwords stay in your computer's keychain.
- **Familiar layout:** a folder tree, a file list with Name, Size, Modified, Rights and Owner, a path bar, and one tab per server.
- **Keyboard first:** F2 rename, F4 edit, F5 refresh, F7 new folder and F8 delete, plus the usual shortcuts.
- **Safe by default:** Sluice checks every server's identity and warns you clearly when it changes.
- **Connections:** SFTP first, then SCP, FTP and FTPS, WebDAV, Amazon S3 and S3-compatible storage.
